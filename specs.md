# SPECIFICATION: X-Radar Growth Engine (Node.js + TwitterAPI.io + Grok Build CLI)

## 1. System Overview & Architecture
You are tasked with building **X-Radar**, an automated X (Twitter) intelligence, trend discovery, and growth engine tailored for the **Indie GameDev** and **Solana** ecosystems.

### Core Tech Stack:
- **Runtime:** Node.js 22 LTS + TypeScript 5.x (Strict Mode, ESM).
- **Database:** SQLite via `better-sqlite3` (WAL mode enabled for concurrent read/write).
- **Validation:** `zod` for strict runtime validation of external API responses and AI JSON outputs.
- **Data Ingestion:** `TwitterAPI.io` REST endpoints (`/twitter/tweet/advanced_search`).
- **AI Synthesis Engine:** Local execution of `grok-build` CLI in headless mode (`grok-build -p`) invoked via `node:child_process.spawn`.
- **Testing & Harness:** `vitest` for unit, contract, and pipeline harness testing (using deterministic mock wrappers for external APIs and CLI binary).
- **Containerization:** Docker + Docker Compose with persistent volume mounts for SQLite data, generated workspace artifacts, and host Grok CLI authentication state.

   - Implement exponential backoff (3 retries on HTTP 429 / 5xx).
   - Parse response with a strict `Zod` schema and normalize tweet objects into the database format.

### Phase 4: Mathematical Scoring & Timing Engine (`src/services/scorer.ts`)
Before calling Grok CLI, process raw data deterministically in Node.js:

1. **Anomaly Virality Score ($V_{\text{score}}$):**
   Implement pure function `calculateViralityScore(tweet, now: Date): number`:
   $$V_{\text{score}} = \frac{\text{likes} + (\text{retweets} \times 2) + (\text{replies} \times 3) + (\text{quotes} \times 4)}{\max(\text{author\_followers}, 100)} \times \frac{1}{(\text{hours\_since\_posted} + 2)^{1.5}} \times 1000$$
2. **Influencer Watchlist Upsert:**
   - When a tweet is in the top 15% of $V_{\text{score}}$ for the batch:
   - If `author_followers` is between `1,000` and `25,000`, classify as `rising_star` (high reply probability, ideal for direct mentions and mutual engagement).
   - If `author_followers > 25,000`, classify as `whale` (ideal for fast "Reply Guy" commenting within 15 minutes of posting).
3. **Timing & Hashtag Aggregator:**
   - Group top 20% highest-scoring tweets by UTC hour (`0..23`) and day of week.
   - Return `optimalPostingWindowsUTC`: top 3 hours subtracted by 30 minutes (so the user posts right as the wave builds).
   - Calculate engagement-weighted frequency for hashtags and 2-word n-grams.

### Phase 7: Docker & Docker Compose Setup
Create `Dockerfile` and `docker-compose.yml` so the entire service runs cleanly in containers while sharing the host's authenticated `grok-build` config (`~/.config/grok` or API key env).

#### `Dockerfile`
```dockerfile
FROM node:22-bookworm-slim

# Install build essentials for better-sqlite3 and curl/ca-certificates for CLI tools
RUN apt-get update && apt-get install -y --no-install-recommends \
    python3 make g++ curl ca-certificates git \
    && rm -rf /var/lib/apt/lists/*

WORKDIR /app

COPY package*.json ./
RUN npm ci

COPY tsconfig.json ./
COPY src ./src
COPY workspace ./workspace

RUN npm run build && chmod +x src/harness/mock-grok-cli.sh

CMD ["node", "dist/index.js", "daemon"]
```

#### `docker-compose.yml`
